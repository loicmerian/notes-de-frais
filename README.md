# Notes de frais Elidia

Appli web installable (PWA) : scan des justificatifs, lecture par Claude, stockage OneDrive, clôture mensuelle envoyée au comptable.

Site : https://loicmerian.github.io/notes-de-frais/

Le code source est dans `source.zip` (Vite). Construction : `npm install && npx vite build`.
